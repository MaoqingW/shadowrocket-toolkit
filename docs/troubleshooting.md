# 故障排查

| 现象                   | 检查步骤                                                                                                    |
| ---------------------- | ----------------------------------------------------------------------------------------------------------- |
| 模块无法保存           | 检查 UTF-8 文本、元数据、段名和重复段。先尝试本地粘贴并记录 App 版本。                                      |
| URL 无法导入或更新     | 检查 URL 是否返回模块原文。私有仓库先下载本地副本再导入。                                                   |
| 规则未命中             | 在请求日志核对真实域名、路径、方法和当前生效配置。检查缓存、已有模块和主配置是否改变路径或代理方式。        |
| HTTPS 路径或正文不可见 | 检查目标是否确实走 Shadowrocket、精确主机名是否追加以及 CA 信任状态。遇到证书固定时保留记录并停止解密测试。 |
| 脚本不生效             | 检查脚本文件能否加载、触发类型、是否读取正文、正文类型与设备日志。用脱敏样本在本地复现。                    |
| 正常功能受影响         | 先停用新模块恢复。固定同一请求，每轮只启停一个候选模块，对照命中条目和策略。将规则缩到已证实的范围后重测。  |

记录 iOS 与 Shadowrocket 版本、模块提交、重现步骤、网络类型和脱敏命中信息。规则、Rewrite 与脚本的交互用真机复测。若依赖远程脚本，也记录对应脚本版本。
